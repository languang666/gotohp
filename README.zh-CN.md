# gotohp 简体中文版

基于 [xob0t/gotohp](https://github.com/xob0t/gotohp) v0.11.0 的本地化版本。这是非官方 Google 相册桌面客户端，不属于 Google 官方产品。

## 汉化范围

- 主界面、账号选择与账号连接指引。
- 仅上传、上传到指定相册、按文件夹自动创建相册。
- 上传设置、说明提示、进度状态与结果统计。
- Windows 窗口标题与网页语言标记。

保留原来的上传逻辑、配置格式和账号兼容性。部分服务端错误及底层诊断信息仍使用英文。

## 使用

启动程序后添加 Google 账号，将照片或文件夹拖到窗口里：

| 入口 | 作用 |
| --- | --- |
| 仅上传 | 上传到照片库，不加入指定相册 |
| 上传到指定相册 | 输入相册名称或 ID 后上传 |
| 自动创建相册 | 根据文件夹名称归类 |

设置中的“节省存储空间（压缩画质）”关闭时使用原画质。“包含所有子文件夹”控制是否递归上传。“上传后删除源文件”会删除本地源文件，保留原件时请关闭。

项目的免配额上传模式不是官方权益保证，使用前请自行核对上传结果和账号存储用量。

## 配置与隐私

程序支持在可执行文件旁放置 `gotohp.config`，沿用原账号与设置。该文件包含登录凭据，不能提交到仓库、公开分享或随安装包分发。此仓库不包含个人账号、照片、上传日志或机器上的配置文件。

## 构建 Windows 版本

需要符合 `go.mod` 的 Go 工具链、符合 `frontend/package.json` 的 Node.js，以及与项目匹配的 Wails CLI。

```powershell
go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0-beta.21
wails3 build
```

构建流程会安装前端依赖、生成绑定和 Windows 图标/清单，然后生成应用程序。安装要求及更多平台说明参见 [上游 README](README.md)。

本次本地验证：前端类型检查、生产构建、ESLint 检查，以及 Windows 程序启动和中文设置页面显示。
